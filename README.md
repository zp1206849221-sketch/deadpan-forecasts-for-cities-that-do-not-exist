# Deadpan Forecasts for Cities That Do Not Exist

A one-line entry for the make.fun contest "Deadpan Forecasts for Cities That Do Not Exist": a straight-faced broadcast forecast for the invented city of Port Regret, where Thursday rain falls upward and umbrellas remain under city recall.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the forecast line to `/output/entry.txt` (UTF-8, under 160 characters).
